# Contributing

Thanks for helping improve humanize-en.

- Open an issue before adding a new benchmark or large rule set.
- Propose specific before/after examples with **fictional or cleared** details. Do not submit confidential customer data.
- Explain when a pattern causes false positives. Avoid universal lists of forbidden words.
- Cite original public post URLs and differentiate interpretation from evidence.
- Preserve original upstream license and copyright notices.
- Run `python3 scripts/validate_repo.py` before proposing changes.
